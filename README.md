# Sweet Things Stuffed Balloons - Premium Website

Welcome to the official website for **Sweet Things Stuffed Balloons**, a premium brand offering luxurious, handcrafted balloon experiences filled with gourmet sweets and candies.

## 🎈 Features

### Premium Design
- **Modern, Elegant Interface**: Built with a sophisticated color palette featuring deep pinks, gold accents, and smooth gradients
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Floating balloons, slide transitions, and scroll-triggered animations

### Sections
1. **Navigation Bar**: Sticky navbar with smooth scrolling
2. **Hero Section**: Eye-catching banner with animated floating balloons
3. **Products Showcase**: 4 premium product collections with pricing and add-to-cart functionality
4. **Features**: 6 key reasons why customers should choose us
5. **Testimonials**: Customer reviews with 5-star ratings
6. **Contact Form**: Email contact section with business information
7. **Footer**: Social links and copyright information

## 📱 Responsive Breakpoints

- **Desktop**: Full layout
- **Tablet**: Adjusted grid layouts (768px and below)
- **Mobile**: Single column layout with hamburger menu (480px and below)

## ⚡ Interactive Features

### JavaScript Functionality
- **Mobile Menu Toggle**: Hamburger menu for mobile devices
- **Smooth Scrolling**: Anchor link navigation with smooth scroll animation
- **Add to Cart**: Interactive product buttons with visual feedback and notifications
- **Contact Form Validation**: Form validation with success/error notifications
- **Scroll Animations**: Cards animate in as they enter the viewport
- **Navbar Enhancement**: Shadow effects on scroll
- **Keyboard Support**: Escape key closes mobile menu

## 🚀 Getting Started

### Files Included
- `index.html` - Main HTML structure
- `styles.css` - Complete styling and animations
- `script.js` - Interactive JavaScript functionality

### How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/Sahajapinky/sweetthingsballoons.git
   cd sweetthingsballoons
   ```

2. Open in your browser:
   ```bash
   # Simply open index.html in your web browser
   open index.html
   ```

3. Or deploy to GitHub Pages, Netlify, or your preferred hosting service
